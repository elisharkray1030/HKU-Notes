COMP 3297 revision

Software engineering. Six topics, each with a re-teach page and a practice page with worked answers. Built from the course's own lectures L0-L5a, including the in-class answer decks.

How to use this pack

  1. Read the re-teach page first. The model comes before the notation: if you can explain why a diagram exists, drawing it becomes mechanical.
  2. Do the practice page the same day. Try each exercise before opening the steps. For diagram exercises, draw on paper first, then compare notation against the answer's SVG.
  3. Notation is graded in this course. Match the lecture's UML exactly, even where standard UML would draw it differently; the pages flag each divergence.
  4. Tick the "Can you yet?" checklists as you go; your ticks persist in the browser so you can see what has faded in a week.
Exam shape

Expect to read, critique and produce: requirements that can be verified, use case and class diagrams in lecture notation, and SOLID arguments with code. The practice pages drill exactly those.
