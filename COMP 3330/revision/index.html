COMP 3330 revision

Interactive Mobile Application Design and Programming. Seven topics, each with a re-teach page and a practice page with worked answers. Built from the course's own lecture slides (Ch 0-6) and tutorials 1-4.

How to use this pack

  1. Read the re-teach page. It builds the mental model first, then the mechanism, then the API surface. Work through the quizzes as you go.
  2. Do the practice page the same day. Try each exercise before opening the steps: the step reveals model the reasoning, not just the answer.
  3. Tick the "Can you yet?" checklist at the bottom of every re-teach page. Your ticks are saved in the browser, so come back in a week and see what stuck.
  4. Argument beats memorising. The discuss prompts want a position from you.
Exam shape

Written final (30%), A4 cheat sheet allowed both sides. The rest is tutorial exercises and the group project, so the code-reading and UI skills are worth as much as the theory.
