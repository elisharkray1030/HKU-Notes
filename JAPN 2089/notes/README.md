# JAPN 2089 — Notes

Study guides and digests for JAPN 2089 *Twentieth century Japan: History, state and society*.

## Naming

`NN-<topic>.md` for whole-reading notes (the leading number is my own reading order, not
a course week number — JAPN 2089 is assessed by coursework, so there is no published
topic sequence to follow). Per-reading digests live in `digests/<id>.md`, named after the
reading.
