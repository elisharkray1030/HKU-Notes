# LING 2027 — Notes

Study guides and summaries for LING 2027.

## Suggested naming

`NN-<topic>.md` to match the topic it covers, e.g. `04-alternations.md` for
Alternations. The leading number is the revision pack's own numbering, not a course
topic number: the course's topic sequence runs Topic 0 Introduction, 1 Phonetics,
2 Abstraction / contrast / predictability, 3 Phonotactics, and alternations is the
topic that follows on from Topic 3. So `04` slots the note in beside the pack's Topic 04
pages, and the note is linked from the course README.
