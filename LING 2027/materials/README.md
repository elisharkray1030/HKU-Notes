# LING 2027 — Materials

Slides, textbook chapters and handouts for LING 2027, kept here exactly as the course
provides them.

## Nothing is committed here

No PDFs are committed to this folder. The lecture slides, the textbook chapters and
the tutorial decks are the property of their authors and of The University of Hong Kong,
and the set is far too big for a notes repo — ~41 MB in total, of which the textbook
chapters alone are ~29 MB. So the course README commits the inventory only, and the files
themselves stay in the local course folder:

```
/home/elijahdelgado/Documents/HKU/LING 2027
├── Textbook/    7 chapters of Zsiga, The Sounds of Language (all 7 on disk)
├── Slides/      lecture decks, Topics 0–4 (all 5 on disk)
├── Tutorial/    tutorial decks A–E, incl. answer sets (all 7 files on disk)
├── Reference/   official IPA chart (Kiel 2015), added 25 Oct 2026
└── Notes/       per-reading study sets (Ch11.1-*, Ch11.2-3-* only — 3 units still to write)
```

`MATERIALS-AUDIT.md` in that folder is the dated record of what is on disk, what is still
missing and which deck pages are image-only.

Corrections to earlier versions of this file (checked 22 Oct 2026, re-checked and
completed 25 Oct 2026): the folder is `Documents/HKU/LING 2027`, not
`Documents/HKU/Year 4/Sem 1/LING 2027`; the local subfolders are `Slides/` and `Tutorial/`
(singular), not `Lectures/` and `Tutorials/`; and every lecture and tutorial deck the
course issues is now present locally, downloaded from Moodle on 25 Oct 2026. The earlier
note that no deck was on disk, and that the notes' Topic 3 / Tutorial D material came from
earlier reading rather than a file, no longer applies.

## Convention

- Drop slides and handouts into this folder exactly as provided by the course, including
  the answer decks, and list each one in the `## Materials` table in
  [`../README.md`](../README.md), flipping its **On disk** column.
- Materials are read-only: they are not mine to edit or republish.
- If the repository ever needs to carry the PDFs themselves, use Git LFS (see the root
  README).
