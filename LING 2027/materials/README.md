# LING 2027 — Materials

Slides, textbook chapters and handouts for LING 2027, kept here exactly as the course
provides them.

## Nothing is committed here

No PDFs are committed to this folder. The lecture slides, the six textbook chapters and
the tutorial decks are the property of their authors and of The University of Hong Kong,
and the set is far too big for a notes repo — ~37 MB in total, of which the six textbook
chapters alone are ~26 MB. So the course README commits the inventory only, and the files
themselves stay in the local course folder:

```
/home/elijahdelgado/Documents/HKU/Year 4/Sem 1/LING 2027
├── Textbook/    6 chapters of Zsiga, The Sounds of Language
├── Lectures/    Topic 0-3 decks
└── Tutorials/   Tutorials A-D, plus the Zsiga exercise pages
```

## Convention

- Drop slides and handouts into this folder exactly as provided by the course, including
  the answer decks, and list each one in the `## Materials` table in
  [`../README.md`](../README.md).
- Materials are read-only: they are not mine to edit or republish.
- If the repository ever needs to carry the PDFs themselves, use Git LFS (see the root
  README).
