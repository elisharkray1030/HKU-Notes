How to use this pack

  1. Read the re-teach page first. The analysis comes before the rule sentence: if you can say which environments select which allomorph, and why, writing the rule becomes mechanical.
  2. Do the practice page the same day. Try each exercise before opening the steps; the step reveals model the reasoning, not just the answer.
  3. Write in the course's own notation: phonemes in /slashes/, surface forms in [brackets], environments framed as ___X, features as [+high]. Answers are graded on discussion, so state two things and explain each.
  4. Tick the "Can you yet?" checklist as you go; your ticks persist in the browser, so you can see what has faded in a week.
