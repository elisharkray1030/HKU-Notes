Phonetics: practice

Drills on the three consonant parameters — voicing, place, manner — and on the descriptions the course's own answer keys accept, in their fixed order. IPA in both directions: symbol to description to English word, and word to transcription. Then vowels on height, backness and rounding, and one problem where a language's consonant inventory, not your English intuitions, decides the answer. Several drills expect you to read a symbol off the IPA chart rather than recall it, because that is the condition the exam sets.

Background: Phonetics.

Exam shape

The Topic 4 deck's last slide publishes the midterm scope: "Phonetics (including non-English, but you will be given an IPA chart with the exam)", then abstraction/contrast/predictability, phonotactics, and alternations (Topic 4, slide 31). Two consequences for this page. First, you are not being tested on having a hundred symbols in your head — you are being tested on knowing which row and column to look in, and on writing the description in the order the course marks. Second, the phonetics questions are not English-only, so a symbol you have never produced is fair game: find it on the chart, read off its place and manner, then describe it. No weighting or mark allocation is published anywhere in the course materials, so none is quoted here.

Quiz

Q1

The course's answer keys name consonants in a fixed order. For [ɹ], which line is written in that order?

Tutorial A states the convention outright — "Consonants are named in the order of '(other) - voicing - place - manner'. Vowels are named in the order of 'height - backness - rounding'" — and its key gives "(voiced) alveolar approximant" for [ɹ]. Options 2 and 3 keep the right three labels in the wrong slots, which is how marks are lost without the answer being factually wrong; option 4 is the description of a different sound, the alveolar trill [r]. Zsiga draws that contrast sharply: in narrow transcription "[r] = alveolar trill and [ɹ] = (post-)alveolar approximant" (Ch. 3, p. 44), and English "road" begins with the approximant.

Q2

The glide [w] is written with one symbol. What does that one symbol stand for?

Zsiga separates contour segments from complex segments and files [w] with the second kind: "Complex segments have two different articulations at the same time. We have already discussed one complex segment: [w], the labio-velar glide, which combines an approximant constriction at both the velum and the lips" (Ch. 3, p. 45). The course's own label says the same thing twice over — Tutorial A's key calls [w] a "voiced labial-velar approximant", and two place names in one label is the tell. So this is the first place the assumption "one symbol = one sound" fails: one symbol, one segment, two articulations. Option 4 confuses [w] with the labiodental approximant, which is a different sound and a different symbol.

Q3

The vowel in "mud" is [ʌ]. Which description matches the course's key?

Tutorial A's key gives "[ʌ] open-mid back unrounded vowel / mid-low back unrounded vowel", and either the open/mid/low vocabulary or the close/open vocabulary is accepted — the IPA chart itself uses "open-mid", which is why both are printed. Option 2 is [ɑ] (Tutorial A: "open back unrounded vowel"), option 3 is [ə] ("mid central (unrounded) vowel"), option 4 is [œ]. One honest caveat: Zsiga describes the tongue position of the wedge as "a neutral tongue position, somewhat back of central" (Ch. 4, p. 63). The label on the chart is "back"; the articulatory gloss is looser. Write the chart's label, and do not let the book's prose talk you into "central", which the course would mark wrong.

Q4

Using the chart, which symbol is the voiced palatal nasal?

Read the chart by row and column: the nasal row, the palatal column, and the cell has one symbol, so it is voiced — [ɲ], the sound in Spanish "año" and French "agneau" (Ch. 3, p. 39). The distractors are the neighbouring cells: [ŋ] is the velar nasal, [n] the alveolar, [ɳ] the retroflex (the retroflex series carries the hook that "recalls the turned-up tongue", Ch. 3, p. 39). This is the whole point of being handed a chart: three of these four differ only in column, so the description tells you exactly where to look.

Q5

A narrow transcription of "spit" is which of these?

Two of the chapter's English rules decide it, and they point the same way. Rule i: "Voiceless stops are aspirated in word-initial position, or beginning a stressed syllable." Rule ii: "Voiceless stops are unaspirated after [s]" (Ch. 3, p. 48). So "pit" is [pʰɪt] but "spit" is [spɪt] — the [s] blocks the aspiration. Option 4 invents voicing assimilation, which English does not do here; the stop stays voiceless, it just loses its puff. Zsiga's broader point: aspiration is not contrastive in English, which is why a broad transcription may leave it out while a narrow one includes it (Ch. 3, pp. 36, 48).

Pitfall

The commonest lost mark on this material is not a wrong symbol. It is a description with the voicing missing, or with the labels in the wrong order: "alveolar voiced approximant" instead of "(voiced) alveolar approximant", "lateral" where the answer needs "lateral fricative" or "lateral approximant". Two habits fix both. Say the order to yourself before you write — other, voicing, place, manner, and for vowels height, backness, rounding. Then check that every term you wrote is one the chart can show you: if you cannot point to the row, the column, or the diacritic, you have invented a term.

Step 1: place the symbol before you name it

For each symbol, find the cell first. The columns run bilabial, labiodental, dental, alveolar, post-alveolar, retroflex, palatal, velar, uvular, pharyngeal, glottal. The rows run plosive, nasal, trill, tap or flap, fricative, lateral fricative, approximant, lateral approximant. Then read the voicing off the cell: "Symbols to the right in a cell are voiced, to the left are voiceless" (the chart's own note).

Step 2: write in the fixed order, and check the near neighbours

Other – voicing – place – manner. Then ask what the neighbouring cells hold, because that is where wrong answers come from: [x] next to [ɣ], [ŋ] next to [ɲ], [k] next to [c], [r] and [ɾ] next to each other on the tap/trill rows.

Full answer

Descriptions.

[ɸ] voiceless bilabial fricative · [β] voiced bilabial fricative · [ɣ] voiced velar fricative · [ɲ] voiced palatal nasal · [q] voiceless uvular plosive · [c] voiceless palatal plosive · [ɾ] voiced alveolar tap · [ʔ] voiceless glottal plosive (glottal stop).

Where each one is easy to get wrong.

[ɸ] and [β] are bilabial, not labiodental: the constriction is between the two lips, with no tooth contact. Zsiga gives both — the voiceless one occurs in Japanese "futon" and, in English, in the exclamation written "phew!"; the voiced one is how most dialects of Spanish pronounce "b" between vowels, "la bola" [laβola] (Ch. 3, pp. 37–38).

[ɣ] is a fricative. The tempting wrong answer is "approximant", because [ɣ] sounds like a buzzy [g]; but the velar approximant is a different symbol and a different row. Zsiga points out that velar fricatives "do not occur in English" and tells you how to make one by loosening a [k] (Ch. 3, p. 40) — that is the diagnostic: frication, not just voicing.

[ɲ] is palatal, and the whole point of Q4 is that its neighbour [ŋ] is velar. [c] is palatal, not velar; the palatal stops are [c] and [ɟ], and Zsiga notes that they are cross-linguistically marked and tend to turn into affricates (Ch. 3, p. 40).

[ɾ] is a tap, not a trill and not a plosive. The alveolar trill is [r] and the English approximant is [ɹ]; the tap is the ballistic one, "throwing" the tongue tip at the ridge (Ch. 3, pp. 42–43) — the sound in American "city".

[ʔ] cannot be voiced, and that is not a fact about this language: the glottal stop is "necessarily voiceless", because voicing requires the folds to be apart and vibrating, which is the opposite of what a glottal closure is (Ch. 3, p. 41). If you wrote "voiced glottal plosive", you have described something impossible.

Reasoning chain: find the cell → read voicing from left/right in the cell → name place from the column and manner from the row → put the four slots in the course's order → check the nearest neighbouring symbol, because that is the distractor the examiner expects.

Full answer

The words. [ˈsɪŋə] singer · [ˈfɪŋgə] finger · [naɪt] knight · [ˈʃʊgə] sugar · [ˈaɪlənd] island · [ˈnɒlɪdʒ] knowledge (US [ˈnɑlɪdʒ]).

What the spelling hides.

singer — ⟨ng⟩ is one sound, [ŋ], and there is no [g]. Zsiga uses "sing" and "singer" for the point that [ŋ] occurs in medial and final position in English but never word-initially (Ch. 3, p. 36); finger is the contrast that shows the letters do not settle the question.

finger — the same two letters, ⟨ng⟩, now stand for two sounds, [ŋ] and [g]. So ⟨ng⟩ has no fixed phonetic value. (Some varieties do pronounce a [g] in "singer" too; if yours does, transcribe [ˈsɪŋgə] and say so. The point is unchanged: the letters do not determine the sounds.)

knight — ⟨k⟩ is silent and ⟨gh⟩ is silent. Six letters, three sounds.

sugar — ⟨s⟩ stands for [ʃ], not [s]. Nothing in the letter tells you; only the word does.

island — ⟨s⟩ is silent, and the vowel is the diphthong [aɪ]. The ⟨s⟩ is there because of a false etymology, not because of a sound.

knowledge — ⟨k⟩ silent, ⟨o⟩ = [ɒ] (US [ɑ]) with the ⟨w⟩ silent too, ⟨dge⟩ = [dʒ] as a single affricate.

The assumption being broken, named. "One symbol = one sound" is false in both directions. From letters to sounds: one letter can be silent (knight, island), can stand for an unexpected sound (sugar), and a two-letter sequence can be one sound in one word and two in another (singer vs finger). From IPA symbols to sounds: one symbol can cover two simultaneous articulations ([w], Q2), and one segment can need two symbols ([tʃ] in Exercise 6, since "the IPA chart contains no symbols for affricates" but "an affricate can always be represented by a sequence of two symbols", Ch. 3, p. 44). Whenever a transcription question looks hard, the difficulty is almost always that you are reading letters.

Reasoning chain: sound the transcription out → match the sound sequence to a word → count segments against letters → name the mismatch → only then write the word.

On variants. Where a word's transcription differs by accent, give both rather than choosing. The course's keys do exactly that, and Tutorial A's key goes further and prints a Hong Kong variant for some words (for example "they" as [deɪ]). If your own variety differs from both columns, write what you say and label it — a labelled variant is a correct answer; an unlabelled one that matches neither column looks like an error.

Reasoning chain: segments first → accent second → stress mark before the stressed syllable → syllable count checked against vowel count → variants printed side by side, labelled.

Step 1: put the symbol on the chart before you describe it

Height is the vertical position, backness the horizontal. The chart's left-right pairing gives rounding: "where symbols appear in pairs, the one to the right represents a rounded vowel" (Ch. 4, p. 58). So rounding is not something to remember separately for each symbol — it is encoded in which side of the pair the symbol sits on.

Step 2: watch the pairs that are not minimal

[i]/[ɪ], [ʊ]/[u] and [ɛ]/[e] differ in height and tenseness at once, in English. Do not describe [ɪ] as "short [i]": height and tenseness are two dimensions, and the course's keys name both.

Step 3: check the rounding note against the chart, not against the key

For each rounded vowel, find its unrounded counterpart on the chart where there is one, and check you have not swapped them. Then look at [ʊ] specifically.

Full answer

Descriptions.

[i] close front unrounded, tense · [ɪ] near-close near-front unrounded, lax (Tutorial B's wording: "near-close/high near-front unrounded vowel // lax high front unrounded vowel") · [ɛ] open-mid front unrounded · [æ] near-open front unrounded (Tutorial B: "near-open front unrounded vowel // near-low front unrounded vowel") · [ɑ] open back unrounded (Tutorial A) · [ɔ] open-mid back rounded · [ʊ] near-close near-back rounded, lax · [ə] mid central unrounded (Tutorial A: "mid central (unrounded) vowel").

The item where the course's key drifts. Tutorial B's key prints [ʊ] with the label "near-close/high near-back unrounded vowel". Symbol and label cannot both be right: [ʊ] is the rounded back vowel of the near-close row — the vowel of "book" — and the chart sets it in the rounded (right-hand) column. Write "near-close near-back rounded". Two reasons to trust the chart over the slip: the chart is what you are handed in the exam (Topic 4, slide 31), and Zsiga states the pairing rule explicitly (Ch. 4, p. 58). If a tutor's key disagrees with the chart, follow the chart and say why in one sentence — that sentence is worth more than the label.

Two more traps in this set. [æ] must be "near-open" or "near-low"; plain "low front" is a different, more peripheral vowel. And [ɑ] must be "open"/"low" and "back"; if you write "central" you have described [ä]-type quality, which the English vowel is not (Ch. 4, p. 65 puts GA "pot" at the backer of the two low vowels).

Why tenseness is not part of the fixed three. The course's stated order for vowels is height, backness, rounding (Tutorial A, p. 1). Tense/lax is a fourth dimension that English uses and many languages do not — Zsiga notes that a five-vowel system like Spanish exploits only three heights and two backnesses, and that tense vowels are "somewhat higher and longer than their lax counterparts" (Ch. 4, pp. 59–60). So add it when it distinguishes, and leave it out when the language does not use it.

Reasoning chain: locate the symbol on the chart → read height from the row, backness from the column, rounding from the side of the pair → write height–backness–rounding → add tense/lax only if the language contrasts it → check the rounding against the chart, not against memory.

Full answer

1. Inventory from the data. Consonants: [ɸ], [ɲ], [q], [c], [ɾ], [t], [ɣ], [m]. Vowels: [a], [e], [i], [o]. The sample is small — ten words, and the list is what the data show, not necessarily the whole inventory. Say that in an answer; it is true of every problem set and it is the kind of hedge that earns credit rather than losing it.

2. Descriptions. [ɸ] voiceless bilabial fricative · [ɲ] voiced palatal nasal · [q] voiceless uvular plosive · [c] voiceless palatal plosive · [ɣ] voiced velar fricative · [ɾ] voiced alveolar tap.

3. English. None of the six is a phoneme of English: English has no minimal pair that turns on any of them. But two do occur in English as positional variants. [ɸ] is the bilabial fricative Zsiga hears in the exclamation written "phew!" (Ch. 3, p. 37), and [ɾ] is the tap that replaces /t/ and /d/ between vowels before an unstressed syllable — "city", "pretty", "lady" (Ch. 3, pp. 43, 50). [ɣ] is not an English sound at all: "velar fricatives do not occur in English" (Ch. 3, p. 40). So the honest answer distinguishes three cases — not a phoneme but a regular allophone, not a phoneme and not a sound, and phoneme — and English supplies examples of the first two.

4. Natural class. {q, c, t} are the voiceless plosives of this inventory. Note what the class is not: it is not "the voiceless sounds", because [ɸ] is voiceless too and is a fricative. Defining the class by two features — [−voice, −continuant] — gets {q, c, t} and excludes [ɸ] exactly. This is the move page 2 drills: a natural class is a set that shares features, not a set that shares a description.

5. Spelling → IPA. ngoxa = [ˈɲoɣa]; phaci = [ˈɸaci]. The mapping is stated in the question, so nothing here depends on knowing the language — which is the point. When a question hands you an orthography, the orthography is data; when it does not, letters are not data at all (Exercise 2).

Reasoning chain: harvest symbols → describe by chart position in the fixed order → ask separately whether English has each sound as a phoneme and as an allophone → define the natural class by features, not by a list → apply the given spelling conventions mechanically.

(4) State the generalisation as one rule, naming the class of targets and the class of triggers. Would "before front vowels" be safe? Step 1: count the data items

Before any analysis, check the list for repeats. A list of ten rows is not necessarily ten words, and an environment list built from a repeated row will double-count one environment.

Step 2: write environments, not impressions

For each occurrence, write the preceding sound, ___, and the following sound. Then sort by symbol. Do this mechanically: the pattern is in the frames, and impressions about "how the word sounds" are what the frames are for.

Step 3: test the frames against the inventory

Two questions at once. Are the two sets of frames disjoint? And is every symbol you wrote down a member of the inventory? A symbol that is not in the inventory cannot be a phoneme of the language.

Step 4: generalise no wider than the data

Look at which vowels actually occur after [s] and [t], and which do not occur at all. A rule that covers a vowel you have no data for is a guess, and the course warns against both directions of error: "DO NOT be too specific or overgeneralize the patterns" (Tutorial C, p. 15).

Full answer

1. Nine distinct words, ten rows. [ˈsapo] "fish" appears twice, in the first row and the last. That is a deliberate duplicate: it is one word, and its environment #__a counts once. An answer that reports ten words, or that lists #__a twice as if it were two pieces of evidence, has been caught by the trap.

2. Environments.

[s]: #__a (sapo) · #__o (sola) · a__a (masa)
[ʃ]: #__i (ʃika) · #__i (ʃiwa)
[t]: #__a (tama) · #__u (tuna)
[tʃ]: #__i (tʃina) · #__i (tʃiʔi)

3. Yes, both pairs. [ʃ] occurs only before [i]; [s] never occurs before [i] anywhere in the data. [tʃ] occurs only before [i]; [t] never occurs before [i]. No symbol appears in both lists of a pair, and every occurrence is accounted for. So [s] and [ʃ] are in complementary distribution, and so are [t] and [tʃ].

4. The rule. Alveolar obstruents become post-alveolar before [i]: /s/ → [ʃ] and /t/ → [tʃ] / ___ [i]; [s] and [t] occur elsewhere. The targets are a natural class — the alveolar obstruents {s, t}, which share [−voice] and place — and the trigger is a single vowel, [i].

"Before front vowels" is not safe, and this is the second trap. The only front vowels in the inventory are [i] and [e], and the data contain no [se], [te], [ʃe] or [tʃe] at all — [e] never follows [s] or [t] anywhere in the nine words. So the data tell you about [i] and are silent about [e]. Writing "front vowels" claims more than you can show; writing "before [i]" is exactly what you can show, and you can add one sentence noting the gap: "the data contain no sequence of [s] or [t] before [e], so whether [e] also triggers the change is not determined." That sentence is the difference between a careful answer and an overgeneral one.

5. [ʃ] and [tʃ] are not phonemes of Language H. Neither appears in the inventory, and both occur only in one environment — before [i] — where [s] and [t] never occur. A segment that is absent from the inventory and predictable from its context is an allophone, not a phoneme. The inventory is doing real work here: it is the list of what the language contrasts, and a symbol outside it cannot be carrying a contrast.

6. What is wrong with the English answer. English has /ʃ/ and /tʃ/ as separate phonemes: "ship" and "sip" are a minimal pair, and "chip" and "tip" are another, so the two sounds distinguish words in English and must be stored. Language H has no such pairs — [s] and [ʃ] never occur in the same environment, so nothing could contrast — and the inventory confirms the absence. The error is not a small one: it substitutes knowledge of English for evidence about Language H, which is the single most common way to lose marks on a data question. The evidence you are entitled to use is the inventory plus the environments; both are in front of you, and both point the other way.

One more thing to say, and it is a description not an analysis. [tʃ] is written with two symbols but is one segment — "the IPA chart contains no symbols for affricates" and "an affricate can always be represented by a sequence of two symbols" (Ch. 3, p. 44). So the tie-barred [t͡ʃ] and the plain [tʃ] are the same claim. Do not let the two symbols tempt you into counting it as a cluster; that is the "one symbol = one sound" error running in reverse.

Reasoning chain: count the rows and find the duplicate → write every environment as a frame → check disjointness within each pair → check every symbol against the inventory → generalise to the narrowest true statement and name the data gap → state which segments are allophones and why English is irrelevant.

Recap

Can you yet?

  • I can state the course's description order for consonants and for vowels, and write three examples of each without looking.
  • I can take an unfamiliar symbol and describe it from the chart's row, column and cell position.
  • I can transcribe six English words in both UK and US, and say which letters are doing no work.
